# RafGodwin shop + admin: how to run it

## 1. Start it (needs only Python 3.9+, nothing to install)
    ADMIN_PASSWORD="choose-a-strong-password" python3 server.py
Site: http://localhost:8000   Admin: http://localhost:8000/admin.html
(Windows PowerShell:  $env:ADMIN_PASSWORD="choose-a-strong-password"; python server.py)

If you skip ADMIN_PASSWORD a random one is created and saved in data/admin_password.txt.
To try it with sample products first: `python3 server.py --demo` (delete them in Admin before going live).

## 2. Using the admin (/admin.html)
- Products: add / edit / hide / delete, up to 6 photos each (auto-resized), price in GH₵, optional stock count.
- Orders: every checkout appears in the Orders tab (green count; page refreshes itself every 25s).
  Open an order to see items, customer, address and payment choice; change status
  (New > Confirmed > Out for delivery > Delivered / Cancelled), add a private note, or tap "WhatsApp customer".
- Stock drops automatically when an order is placed and returns if you cancel it.

## 3. Putting it online
The site now has a backend, so it needs a host that runs Python (a small VPS, Render, Railway,
PythonAnywhere, etc.). Plain static hosting (GitHub Pages, Netlify drop) cannot run the shop.
- Set env vars: ADMIN_PASSWORD, PORT (if the host tells you), COOKIE_SECURE=1 once you have https.
- Serve it over https (host-provided, or Caddy/nginx in front).
- BACK UP the `data/` folder (shop.db + uploads/): it holds all products, photos and orders.
- Set DATA_DIR to a persistent disk if your host wipes the app folder on deploy.

## 3b. Using Netlify for the website (recommended setup)
Netlify can only host the static pages, so run it in two parts:
1. Put the whole folder on a Python host (Render.com web service works: start command `python3 server.py`).
   Add env vars: ADMIN_PASSWORD, COOKIE_SECURE=1, TRUST_PROXY=1, SITE_ORIGIN=https://your-site.netlify.app,
   and DATA_DIR pointing at a persistent disk (otherwise orders/photos are lost on redeploy).
2. Open `netlify.toml`, replace both YOUR-BACKEND-URL with that host's address, then deploy the folder to Netlify.
Netlify then forwards /api and /uploads to the backend, so the shop and /admin.html work on your Netlify address.
Until step 1 is done the shop will show "could not load" and admin login will not work.

## 4. Editing the site
Pages are generated by build.py (run `python3 build.py` after editing it). Shop/admin files:
shop.html, assets/js/shop.js, assets/css/shop.css, admin.html, assets/js/admin.js, assets/css/admin.css, server.py.
